▸ Patient Memory Architecture
INDIVIDUAL Individual Memory
SHORT-TERM LONG-TERM
  • Short-term: Recent vital sign fluctuations, current-cycle adverse event trajectory
  • Long-term: Complete medical history, genomic profile, historical drug tolerance
  • Continuously updated individual baseline model
  • Enables "current anomaly vs. patient's own history" comparative reasoning
COMMUNITY Community Memory
EMERGENT SIGNAL COHORT PATTERN
  • Cross-patient cohort pattern aggregation
  • Example: Multiple hypertensive patients reporting the same adverse reaction → system auto-generates a population-level insight
  • Early signal amplification for rare adverse events
  • Automated discovery of drug–patient subtype associations
Real-Time Risk Assessment Engine
  • DLT / CTCAE Grade prediction with confidence intervals
  • Early physiological signature detection for infection, thrombosis, and CRS
  • Risk scoring powered by both Individual and Community Memory
Anomaly Detection Module
  • Statistical deviation detection against individual baseline
  • Multi-signal joint anomaly (e.g., SpO₂↓ + HR↑ + Activity↓)
  • Outputs structured Anomaly Events → triggers Aim 2
▸ Aim 2 · Proactive Conversational Agent
AIM 2
Proactive, Memory-Personalized Patient Engagement & SAE Prevention
Proactive anomaly response · Personalized dialogue · Real-time ESI triage · Adherence monitoring
Proactive Trigger Engine
⚡ Anomaly Signal from Aim 1
  • Aim 1 anomaly events proactively initiate patient outreach
  • Scheduled protocol milestone check-ins
  • Adherence deviations (missed doses / delayed reporting) trigger immediate intervention
  • Community Memory population-level alerts trigger targeted patient queries
Personalized Dialogue Agent
  • Individual Memory–driven personalized conversation opening
  • Adaptive language complexity for health literacy level
  • Multi-turn conversation context management
  • Structured symptom elicitation aligned with FDA COA standards
ESI Triage via Dialogue
  • Real-time ESI Level 1–5 estimation during conversation
  • Immediate recognition of critical danger signs (dyspnea, altered consciousness)
  • High-risk conversation → structured summary report → escalate to Aim 3
  • Low-risk → log ePRO data + update Individual Memory
Adherence & SAE Monitor
  • Oral medication confirmation and missed-dose detection
  • SAE reporting delay alerts and proactive follow-up
  • Patient engagement scoring
  • ePRO data quality validation
▸ Aim 3 · Collaborative Intelligence & AI Trust Framework
AIM 3
Human-in-the-Loop Approval · Workload-Aware Routing · AI Trust
AI outputs are never acted on directly · Explainable approval interface · Clinician resource-aware · Individual–workload balance
▸ AI Trust Core — Human Approval Gateway
Explainable Output Interface
  • AI never directly executes any clinical action
  • Every recommendation is rendered as a human-readable, one-page approval brief
  • Includes: data sources · reasoning chain · confidence visualization
  • Clinician one-click: ✓ Approve / ✎ Modify / ✗ Reject
Uncertainty & Audit Trail
  • Low-confidence recommendations flagged ⚠ for mandatory human review
  • Full audit log retained for every decision
  • Rejected / modified cases fed back for model recalibration
  • HIPAA / IRB-compliant documentation
Workload-Aware Intelligent Routing
  • Continuously monitors each care team member's real-time availability (schedule · pending tasks · online status)
  • Routes requests by three dimensions: urgency level + specialty match + availability
  • Goal: maximize individual patient benefit ↔ minimize overall clinician burden
